# Команды и пресеты

## Команды

| Команда | Что делает |
|---|---|
| `/streamrewards login` | Вход через Twitch по коду |
| `/streamrewards sync` | Создать награды по пресетам |
| `/streamrewards connect` / `disconnect` | Подключиться к Twitch / отключиться |
| `/streamrewards status` | Состояние мода |
| `/streamrewards test <действие>` | Проверить эффект без Twitch |
| `/streamrewards undo` | Вернуть стёртый чанк (одиночная игра) |

## Пресеты

Лежат в `config/streamrewards.json` (создаётся при первом запуске). Можно менять цены, названия,
кулдауны, выключать пресеты (`"enabled": false`). После изменений названий/цен выполни `/streamrewards sync`.

Поле `scope`: `any` — работает везде, `singleplayer` — только в одиночной игре.
Когда ты на чужом сервере, такие награды автоматически ставятся на паузу в Twitch.

| Действие | Где работает |
|---|---|
| `drop_held` выбросить предмет из руки | везде |
| `drop_inventory` выкинуть инвентарь | везде |
| `random_hotbar` случайный слот хотбара | везде |
| `fov` изменить угол обзора (`value`, `seconds`) | везде |
| `creeper_hiss` шипение крипера | везде |
| `delete_held_item` удалить предмет из руки | одиночная |
| `delete_random_item` удалить случайный предмет | одиночная |
| `delete_armor` удалить броню | одиночная |
| `delete_chunk` стереть всё в чанке от уровня ног и выше (`depth_below`, `skip_block_entities`) | одиночная |

`delete_chunk` по умолчанию не трогает сундуки, печки и другие блоки с данными, а стёртое можно
вернуть командой `/streamrewards undo`.

## Важно

- Файл `config/streamrewards.json` содержит токены доступа. **Не показывай его на стриме**
  и никому не отправляй. Если токен утёк: dev.twitch.tv → Connections → отозвать доступ.
- На чужих серверах действия вроде выброса инвентаря выглядят как автоматизация. Проверь правила
  сервера и не включай такие пресеты без разрешения администрации.
- Код написан без возможности запустить сборку. Если при компиляции будут ошибки в названиях
  методов Minecraft, пришли текст ошибки, и всё быстро поправим.
