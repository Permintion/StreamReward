# Stream Rewards (Fabric 1.21.11)

Награды за баллы канала Twitch -> эффекты в Minecraft. Клиентский мод.

## Как собрать (Windows)

1. Установи Java 21 (JDK), например Temurin 21: https://adoptium.net/
   Проверка: открой командную строку и введи `java -version` — должно быть 21.
2. Открой командную строку В ЭТОЙ ПАПКЕ (в проводнике: клик по адресной строке, набери `cmd`, Enter).
3. Выполни: `gradlew.bat build`
   Первый раз качает много файлов (10-20 минут, нужен интернет).
4. Готовый мод: `build\libs\streamrewards-1.0.0.jar` (файл БЕЗ `-sources` в названии).

macOS / Linux: `chmod +x gradlew && ./gradlew build`

## Как поставить в игру

1. Fabric Loader для 1.21.11 (https://fabricmc.net/use/installer/).
2. Fabric API для 1.21.11 (Modrinth или CurseForge) — положить в папку `mods`.
3. `streamrewards-1.0.0.jar` — туда же, в папку `mods`.

## Быстрый тест без установки

`gradlew.bat runClient` запускает Minecraft с модом прямо из проекта.

## Меню наград

Команда `/streamrewards` (или `/streamrewards menu`) открывает меню: вкл/выкл награды, цена, кулдаун, кнопка «Тест».
После изменений нажми «Применить на Twitch».

## Длительность эффектов, инвертированное управление, выход из аккаунта

- В меню у наград с эффектом по времени есть колонка «Длит.» (секунды): можно менять, сколько длится эффект. Описание награды на Twitch подстроится после «Применить на Twitch».
- «Инвертировать управление» меняет местами W/S и A/D на время эффекта. Исходные клавиши запоминаются, так что даже после сбоя игры при следующем запуске всё вернётся.
- Выйти из аккаунта Twitch: кнопка «Выйти из аккаунта» в меню (нужно нажать дважды) или `/streamrewards logout`. Награды на канале ставятся на паузу, токен отзывается.

## Блокировка мыши и клавиатуры, языки

- «Заблокировать мышь»: на время эффекта не работает поворот камеры и клики мыши.
- «Заблокировать клавиатуру»: не работают все клавиши управления (движение, прыжок, инвентарь...), чат и команды доступны, Esc тоже работает.
- Интерфейс мода, сообщения и названия стандартных наград переводятся вместе с языком Minecraft: русский, английский, украинский (файлы в `assets/streamrewards/lang`). Названия самих наград на Twitch берутся из `config/streamrewards.json`.

## Сообщения в чат

Когда зритель покупает награду, в чат игры (локально, видишь ты и зрители на стриме) пишется:
`{Ник} Купил награду {Название}`. Включается кнопкой «Чат» в меню. Шаблон по умолчанию зависит от языка Minecraft; свой шаблон задаётся в `config/streamrewards.json`
(поле `chatFormat`, доступны `{user}`, `{reward}`, `{cost}`; пустая строка — шаблон по языку).

## Первый запуск в игре

1. `/streamrewards login` -> открой ссылку, введи код.
2. `/streamrewards sync` -> мод создаст награды на канале.
3. `/streamrewards test drop_held` -> проверка эффекта без Twitch.

Команды и пресеты описаны в `README_MOD.md`. Настройки: `config/streamrewards.json`
(там лежат токены — не показывай файл на стриме).
